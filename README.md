## 🌟 Ключевые возможности

- 🎨 **Современный Cyber/Dark интерфейс**: стильный темный дизайн на `CustomTkinter` с акцентами Cyan и Emerald, плавными элементами и карточками статистики.
- 🛡️ **Полноценный системный VPN (Wintun)**: туннелирование всего трафика Windows через виртуальный адаптер с автоматическим запросом прав администратора (UAC).
- 📱 **Встроенный независимый мост PCVPN**:
  - Локальный прокси-сервер на настраиваемом порту (`24066` по умолчанию).
  - Одновременная поддержка **SOCKS5** и **HTTP CONNECT** на едином порту.
  - Включается и выключается **отдельной кнопкой** независимо от системного VPN.
  - Позволяет раздавать туннель на смартфоны (Android / iOS) по Wi-Fi (совместим с приложением [PC VPN Bridge](https://github.com/ELKAPY/PCvpn-bridge)).
- 🔔 **Умный системный трей**:
  - При закрытии на крестик `[X]` окно сворачивается в системный трей возле часов.
  - При первом закрытии выводится диалог с выбором действия и чекбоксом «Запомнить выбор (больше не показывать)».
  - Контекстное меню трея позволяет **включать и отключать WDTT в один клик** без открытия главного окна.
  - Всплывающие уведомления Windows при сворачивании.
- 🔑 **Управление ключами и пул VK-хешей**:
  - Быстрый ввод и сохранение ключа подключения прямо с главного экрана.
  - **Многопоточный пул звонков**: поддержка добавления нескольких ссылок на звонки для отказоустойчивости.
  - Интерактивная проверка здоровья хешей (`⚡ Проверить хеши`) с индикацией статуса каждого звонка.
- ⚡ **Выбор протокола (DTLS vs Raw-IP)**:
  - Режим `Стандартный DTLS`: маскировка под звонок VK, WireGuard + WinTUN.
  - Режим `Сверхбыстрый Raw-IP (-notls)`: минимальный пинг и прямое ChaCha20-Poly1305 AEAD шифрование (для серверов с `-listen-direct`).
- 🛡️ **Обход блокировок провайдеров**:
  - **Режим TCP TURN (`-turn-tcp`)**: работа через TCP в сетях, где провайдеры урезают или глушат UDP (напр. Ростелеком).
  - **Режим обфускации WebRTC (`-obfs audio/video`)**.
  - **Выбор режима обхода капчи (`-captcha-mode auto/wv/rjs`)**.
- 📊 **Мониторинг и диагностика**:
  - Интерактивный замер задержки (Ping) до сервера в реальном времени.
  - Подсчет переданного и принятого трафика (↓ Скачано / ↑ Отдано).
  - Отображение активных воркеров и времени сессии.
  - Встроенная консоль с живым выводом логов клиента, кнопками очистки и копирования.
  - Интерактивный калькулятор воркеров с кнопками пресетов (кратность 9).
- 📌 **Создание ярлыка в один клик**:
  - Предложение создать ярлык на Рабочем столе при первом запуске.
  - Кнопка создания ярлыка доступна в настройках в любой момент.

## 🚀 Быстрый старт

### Вариант 1. Запуск скомпилированного приложения
1. Скачайте репозиторий или релиз.
2. Запустите **`WDTT.exe`** (или `start.bat`).
3. При необходимости скопируйте `config.example.ini` в `config.ini` и укажите данные вашего сервера.

### Вариант 2. Запуск из исходного кода (Python)
1. Убедитесь, что установлен Python 3.10 или новее.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```

## ⚙️ Настройка `config.ini`

Пример конфигурационного файла (`config.example.ini`):

```ini
# Настройки подключения VK TURN
# Укажите адрес и порт вашего сервера (VPS)
PEER=1.2.3.4:56000

# Пароль подключения (из него выводится HKDF-SHA256 ключ)
PASSWORD=YOUR_PASSWORD

# Хеш VK-звонка (можно несколько через запятую)
VK_HASH=https://vk.com/call/join/YOUR_CALL_HASH

# Количество параллельных воркеров (кратно 9: 18, 27, 36, 45...)
WORKERS=40
```

> ⚡ **Обратите внимание на воркеры**:  
> Ядро `vk-turn-client` запускает воркеры строго группами по 9 штук (`9`, `18`, `27`, `36`, `45`, `54`...).  
> При указании, например, `40` воркеров, клиент запустит `36` (4 группы по 9). В приложении встроен интерактивный калькулятор, который наглядно показывает реальное число запускаемых потоков.

## 📱 Подключение смартфона через PCVPN Мост

1. Подключите компьютер и смартфон к одной сети Wi-Fi.
2. В приложении WDTT перейдите на вкладку **«📱 PCVPN Мост»** и нажмите **«ВКЛЮЧИТЬ МОСТ»**.
3. На экране отобразятся:
   - **IP-адрес ПК в Wi-Fi** (например, `192.168.1.50`)
   - **Имя ПК (mDNS)** (например, `desktop-pc.local`)
   - **Порт** (по умолчанию `24066`)
4. В приложении **PC VPN Bridge** на Android введите указанный IP (или mDNS имя) и порт.
5. Нажмите «Подключить» на смартфоне — весь мобильный трафик пойдет через ваш туннель!

## 🛠️ Сборка исполняемого файла (`.exe`)

Для компиляции автономного исполняемого файла запустите скрипт:

```cmd
build.bat
```

Или вручную через PyInstaller:

```bash
pyinstaller --noconsole --onefile --uac-admin --icon="app_icon.ico" --name="WDTT" --collect-all customtkinter --collect-all darkdetect --collect-all pystray --add-data "app_icon.png;." --add-data "app_icon.ico;." main.py
```

Готовый файл **`WDTT.exe`** появится в корневой папке проекта.
